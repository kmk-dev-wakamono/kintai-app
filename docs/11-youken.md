# 要件定義

## 現状の課題

- 勤怠関係のワークフローが断絶されており、申請漏れがある
- 部の稼働状況の確認が容易でない (個別に確認する必要がある)
- 勤怠書類を個別に入力する必要があり、工数がそれなりにかかる

## 要件

- 現状のExcelはそのまま利用できるようにする必要がある
- 残業は特定のチャットにメッセージを投げる必要がある
  - 今月分のスレッドがある場合はそのメッセージにぶら下げる
- 休む場合はメールを送信する必要がある

## 要求

- 所属部やチームのものを横断的に確認できるようにしたい
  - 残業状況の確認

## 必要な機能

- 認証
  - ログイン / ログアウト
  - Teamsのアカウント情報
- 入力
  - 勤怠 (遅刻・早退・欠勤)
  - 交通費精算
  - 残業
- 確認
  - 勤怠 (遅刻・早退・欠勤)
  - 交通費精算
  - 残業
- 出力
  - 勤怠表
  - 交通費精算書
  - 定期申請書
  - 残業申請 (Teams chat)
  - 勤怠申請 (e-mail)
